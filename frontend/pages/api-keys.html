🔑 مفاتيح API

المفاتيح المحفوظة في متغيرات البيئة تبقى ثابتة عبر جميع التحديثات

🛡️ كيف تحفظ مفاتيحك بشكل دائم؟

قاعدة البيانات تُمسح عند كل تحديث على Render (الخطة المجانية).
لحفظ المفاتيح بشكل دائم: اذهب إلى Render → Environment وأضف المفاتيح كـ Environment Variables باستخدام الأسماء الموضحة أسفل كل حقل.
✓ المفاتيح المضبوطة هناك تظهر بشارة خضراء ولا تُمسح أبداً.

📋 خطوات ربط Supabase:
① افتح supabase.com → New Project
② اذهب إلى Settings → Database → Connection string → URI
③ انسخ الرابط (يبدأ بـ postgresql://postgres...)
④ الصقه في الحقل أدناه واضغط "حفظ وتطبيق"
⚠️ لضمان استمرار الاتصال: أضف المفتاح أيضاً في Render → Environment → DATABASE_URL
