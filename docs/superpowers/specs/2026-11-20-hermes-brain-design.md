# تصميم: Hermes كعقل للمنصة (تشغيل محلي)

## الهدف والسبب
المالك يشغّل Hermes Agent على جهازه (مرتبط بكلود) ويريد أن يكون هو عقل المنصة:
يولّد النصوص، يختار أفضل العروض، ويختار التصنيفات، ويتحكم بالمنصة بالكامل.
المنصة تنتقل من Render إلى نفس الجهاز، فيصبح الاتصال محلياً (localhost).

## الأهداف
1. Hermes هو المزوّد الوحيد للذكاء الاصطناعي: توليد المنشورات وعرض اليوم.
2. Hermes يختار أفضل العروض من قائمة المنتجات (يستبدل `_ai_select_top5`).
3. Hermes يختار تصنيفات اليوم بدل العشوائية (يستبدل `pick_unused_categories_for_today`).
4. Hermes يتحكم بالمنصة عبر واجهة تحكم (اكتشاف، طابور، نشر، إعدادات عادية).
5. النشر على تيليجرام وX مباشر بلا موافقة، ويستطيع المالك إيقافه من تيليجرام.
6. المنصة تعمل محلياً كخدمة دائمة، وتُزال تبعيات Render.

## ما ليس هدفاً
- لا OpenRouter ولا أي مزوّد سحابي للذكاء الاصطناعي (يُحذف الكود والمفاتيح).
- لا صلاحية لـ Hermes على مفاتيح API وتوكنات النشر (قرار المصمم، يمكن تغييره).
- لا استضافة سحابية ولا نفق.

## ما يُعدّ فشلاً
- نشر عرض بسعر أو رابط خاطئ دون أي حاجز.
- توقف النشر كلياً عند تعطل Hermes.
- عدم قدرة المالك على الإيقاف الفوري.

## القرارات (من المالك)
- الاتجاه: **الاثنان معاً**: المنصة تنادي Hermes داخل خط العمل، وتعرض واجهة تحكم يستخدمها Hermes.
- النشر **مباشر** بلا اعتماد، والإيقاف من تيليجرام.
- OpenRouter يُزال.

## الطرق المدروسة
- (أ) المنصة تنادي Hermes فقط: ثابت لكن لا تحكم.
- (ب) Hermes يقود والمنصة أداة: تحكم كامل لكن يتوقف كل شيء بتوقفه.
- **(ج) الاثنان معاً — المختارة**: ثبات خط العمل مع تحكم كامل عند الطلب.

## التصميم

### 1. عميل Hermes (`ai_service.py`)
- يُستبدل المحتوى الداخلي بعميل واحد لواجهة متوافقة مع OpenAI:
  `POST {HERMES_BASE_URL}/chat/completions` مع `Authorization: Bearer {HERMES_API_KEY}`.
- الإعدادات: `HERMES_BASE_URL`، `HERMES_API_KEY`، `HERMES_MODEL`، مهلة (افتراضي 120 ث لأنه وكيل).
- تبقى واجهة الدوال كما هي (`generate_content`، `generate_deal_of_day_content`، `call_ai`) حتى لا يتغير المستدعون في `main.py` و`scheduler.py` و`deals_finder_service.py`.
- يبقى كاش ASIN. يُحذف: اكتشاف النماذج، القوائم الميتة، `SUPPORTED_MODELS`، مزوّد OpenRouter.
- عند فشل Hermes (خطأ/مهلة/رد فارغ): محاولة ثانية واحدة، ثم **القالب الثابت** (`_make_fallback`). يُسجَّل السبب ويُرسل تنبيه للمالك على تيليجرام (مرة كل فترة لا لكل منتج).

### 2. اختيار العروض والتصنيفات
- `_ai_select_top5`: يطلب من Hermes JSON صارماً بأرقام المنتجات المختارة مع سبب قصير. التحقق من الصيغة، وعند الفشل ترتيب حسابي كما اليوم.
- جديد `pick_categories_with_hermes(n)`: يرسل لـ Hermes التصنيفات المتاحة (غير المستخدمة اليوم) مع آخر استخدام وأداء سابق إن وجد، ويعيد n تصنيفاً. عند الفشل: العشوائية الحالية.
- **حواجز الأمان قبل النشر المباشر** (في الكود لا في Hermes): السعر والرابط والـ ASIN تأتي من بيانات المنتج لا من نص Hermes؛ يُرفض أي منشور لا يحوي رابط الإحالة الصحيح أو يحوي سعراً مختلفاً؛ حد أقصى يومي للمنشورات؛ منع تكرار نفس ASIN خلال نافذة (موجود: `autopilot_dedup_hours`).

### 3. واجهة التحكم
- تُعاد استخدام نقاط `main.py` الموجودة (طابور، اكتشاف، سجل، إعدادات عادية).
- مصادقة بمفتاح خاص (`X-Hermes-Key`) مختلف عن مفتاح لوحة التحكم؛ يعمل على localhost فقط.
- قائمة مسموحة صريحة: لا تمر مفاتيح API وتوكنات النشر عبر هذه الواجهة.
- تُوثَّق الأوامر في ملف يُعطى لـ Hermes (مواصفة OpenAPI التي يولدها FastAPI تكفي).

### 4. الإيقاف من تيليجرام (جديد بالكامل)
- مستمع `getUpdates` داخل المنصة يقبل الأوامر من **معرّف المالك فقط** (`OWNER_TELEGRAM_ID`).
- الأوامر: `/stop` (يوقف كل النشر فوراً)، `/resume`، `/status` (الحالة، آخر نشر، حالة Hermes).
- حالة الإيقاف تُخزَّن في الإعدادات (تبقى بعد إعادة التشغيل) ويفحصها كل مسار نشر قبل الإرسال.

### 5. التشغيل المحلي
- SQLite تلقائياً (موجود). ملف `.env` بدل متغيرات Render.
- خدمة دائمة تبدأ مع الجهاز (systemd أو ما يناسب نظامه) وتعيد التشغيل عند الانهيار.
- يُحذف `render.yaml` وإشاراته في README، ويُحدَّث `.env.example`.

## متروك للمنفّذ
- شكل رسالة النظام والتعليمات لـ Hermes، وصيغة JSON بالتفصيل.
- اختيار طريقة الخدمة الدائمة حسب نظام جهاز المالك.
- اختبارات الحواجز (مرفوض: سعر مختلف، رابط ناقص، تجاوز الحد اليومي).

## افتراضات المصمم (للمراجعة)
- Hermes يعرض واجهة متوافقة مع OpenAI على منفذ محلي.
- جهاز المالك نظام يدعم خدمة دائمة (لينكس/ماك/ويندوز).
- المالك يملك بوت تيليجرام ومعرّفه الشخصي.
